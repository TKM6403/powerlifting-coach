# Progression Rules

How loads and RPE adjust day-to-day based on athlete state. SBD Agent references this when proposing modifications.

---

## RPE Definitions (Reps in Reserve)

| RPE | Reps in Reserve | What It Feels Like |
|---|---|---|
| 10 | 0 | Max effort, could not have done another rep |
| 9.5 | 0.5 | Maybe one more rep, very uncertain |
| 9 | 1 | Definitely one more rep, second is uncertain |
| 8 | 2 | Two more reps in the tank |
| 7 | 3 | Three more reps possible |
| 6 | 4 | Four+ more reps, feels easy |
| 5 | 5 | Warmup intensity |

---

## Daily Autoregulation

When tkm reports state at session start, adjust as follows:

### Sleep < 6 hours
- Drop top-set RPE by 1
- Reduce back-off volume by ~10-15%
- No PR attempts

### Significant soreness from prior session
- Drop top-set RPE by 1
- Cut accessories that hit the sore area
- Extend warmup specifically for affected region

### Left-side tightness reported
- Mandatory full mobility warmup with extra hip work
- Drop RPE by 0.5-1
- Reduce volume if pre-warmup mobility doesn't unlock the position
- If pain (not stiffness): consult Mobility Agent for go/no-go

### Feeling great / autoregulated up
- Allowed to hit top of RPE range
- Allowed to add a "bonus" back-off set if intent and energy match
- Don't chase a PR unless it was planned

### Travel or skipped session
- Treat first session back as a reintroduction: -10-15% loads, -1 RPE
- Don't try to "catch up" volume

## Weekly Progression

### Accumulation phase
- Volume rises by ~5% per week (more sets or more reps)
- Intensity holds roughly steady
- Top set RPE creeps 7 → 7.5 → 8 over a few weeks

### Intensification phase
- Volume holds or slightly drops
- Intensity rises (RPE 8 → 8.5 → 9 on top sets)
- Back-off volume tightens

### Realization / peak
- Volume drops significantly
- Specificity rises (competition variations dominate)
- Top set RPE high (9-9.5) but on lower rep counts
- Frequency drops in final week

### Deload triggers
- Two consecutive sessions where prescribed loads feel 1+ RPE harder than they should
- Persistent sleep disruption or mood decline
- Any sustained injury flare
- After 4-6 weeks of accumulation
- Pre-meet (1-2 weeks before competition)

---

## Failure Handling

### Missed planned reps at planned RPE
- One miss: probable bad day, don't change TM
- Two misses on same lift in a block: drop TM by 2.5-5%, recalculate working weights

### Overshooting RPE (e.g., RPE 8 felt like RPE 9.5)
- Single instance: log it, watch trend
- Pattern across week: signal of accumulated fatigue, may need a deload

### Undershooting RPE (RPE 8 felt like RPE 6)
- Single instance: normal, you had a great day
- Pattern across week: TM might be set too low; consider testing

---

## Asymmetry-Specific Rules

- If left-side issues recur for 2+ sessions in a row → mandatory drop in volume and consult Mobility Agent before continuing
- Never replace a regression decision with "just push through it"
- Track stabilizer routine completion alongside SBD numbers — if completion drops below 80%, address before continuing to progress SBD intensity
