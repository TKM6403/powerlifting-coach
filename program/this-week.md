## Supersetting Rules (for this block)

Three supersets only — A (Tue: pushdown + hammer curl), B (Thu: ham curl + cable abduction), C (Sat: lateral raise + rear delt). All are natural pairs (antagonist or non-competing). Rest **60-90 sec between rounds** of a superset, not between the two moves within it. Don't superset main lifts. Don't add new supersets ad-hoc.

- ROM loss vs Mon baseline → pause progression, repeat Wk 1 dosing in Wk 2
